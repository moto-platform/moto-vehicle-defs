# moto-codegen

Generator and consistency checks for moto-vehicle-defs. Run it through the repo `Makefile` (`make check`, `make gen`). Modules: `dbc_checks` (ID plan, E2E layout, DataIDs, naming, the messages SAFETY may receive: D-041), `yaml_checks` (CL250 YAML incl. D-020, DID priority, the D-043 no-starvation bound (`did_sample_gap_bounds`) and the watch-only functional IDs; limits incl. 0 < k_yellow < k_red ≤ 0.8, the speed-age bounds and the per-node `scope`), `gen_uds` (`uds/iso14229.yaml` and `uds/dids.yaml`: checks, `uds_iso14229.h` per node with a D-020 client subset for CONN, `platform_uds.{h,c}` per server node, `moto_defs/uds.py`), `gen_c` (cantools per node + E2E + DID table), `gen_python`, `gen_vss` (pinned COVESA VSS 6.0 + vss-tools 6.0), `e2e` (reference implementation the C code is tested against). Node targets and the ID plan live in `config.py`.
